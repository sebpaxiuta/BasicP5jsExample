# iF/elsE

Desenvolvi uma composição generativa em p5.js que utiliza múltiplas estruturas condicionais para transformar a estética visual em tempo real através dos movimentos e cliques do rato. O eixo vertical altera o fundo entre claro e escuro, enquanto o eixo horizontal e a proximidade do cursor modificam dinamicamente as cores, o tamanho e a forma dos elementos geométricos de uma grelha. Além disso, a pressão de teclas permite alternar instantaneamente entre diferentes modos visuais, criando uma experiência interativa fluida
